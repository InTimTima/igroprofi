Настоящая Политика конфиденциальности (далее — «Политика») определяет порядок обработки и защиты информации о Пользователях сайта igroprofi (далее — «Сайт»), в соответствии с Федеральным законом от 27.07.2006 № 152-ФЗ «О персональных данных».

1. Какие данные мы обрабатываем

1.1. Учётные данные: логин и пароль, которые Пользователь указывает при регистрации. Пароль хранится в локальном хранилище браузера Пользователя и не передаётся на сервер.

1.2. Данные подписки: тариф, дата активации и срок действия подписки.

1.3. Платёжная информация (номер карты, реквизиты) обрабатывается исключительно платёжным сервисом ЮKassa (ООО НКО «ЮМани») и не поступает в распоряжение Администрации Сайта.

1.4. Технические данные: cookies, IP-адрес, сведения о браузере и устройстве — для обеспечения работоспособности и безопасности Сайта.

2. Цели обработки

2.1. Предоставление доступа к платным и бесплатным Интерактивам Сайта.

2.2. Обработка платежей через платёжный сервис ЮKassa.

2.3. Улучшение работы Сайта и поддержка Пользователей.

3. Хранение данных

3.1. На текущем этапе учётные данные и данные подписки хранятся в локальном хранилище браузера Пользователя. При переходе на полноценный серверный аккаунт данные будут храниться на сервере с соблюдением требований законодательства РФ.

3.2. Платёжные данные хранятся и обрабатываются сервисом ЮKassa в соответствии с его правилами и требованиями законодательства.

4. Передача данных третьим лицам

4.1. Данные передаются третьим лицам только в объёме, необходимом для обработки платежей (сервис ЮKassa) и обеспечения работы Сайта (хостинг-провайдер).

4.2. Иные случаи передачи данных возможны только в соответствии с законодательством РФ.

5. Права Пользователя

5.1. Пользователь вправе удалить свои данные из браузера, очистив локальное хранилище Сайта, либо запросить удаление данных у Администрации.

5.2. Для реализации прав Пользователь может обратиться по адресу электронной почты, указанному в разделе 7.

6. Файлы cookie

6.1. Сайт может использовать файлы cookie и аналогичные технологии для хранения настроек языка и предпочтений. Пользователь может отключить cookie в настройках браузера, однако это может повлиять на работу Сайта.
